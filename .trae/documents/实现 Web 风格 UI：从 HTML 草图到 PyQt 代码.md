### **重构计划：Web 风格 PyQt 实现**

我们将抛弃传统的 Tab 布局，转而使用更现代的“侧边栏 + 堆叠页面”架构。

#### **1. 样式升级 (`styles.py`)**
我们需要将 HTML 中的 CSS 样式“翻译”为 Qt 的 QSS (StyleSheet)。
*   **全局配色**: 引入 `design_concept.html` 中的深色调色板（`#1e1e1e`, `#252526`, `#007acc`）。
*   **侧边栏样式**: 为侧边栏按钮（QListWidget 或 QToolButton）设计 Hover 和 Selected 状态，模拟 Web 导航栏的体验。
*   **卡片容器**: 实现圆角、阴影和深色背景的卡片样式 (`#2d2d30`)，用于包裹配置项。

#### **2. 核心布局重写 (`ui.py`)**
*   **主框架**: 使用 `QHBoxLayout` 将窗口分为两部分：
    *   **左侧 (Sidebar)**: 一个垂直的导航栏，包含“新建下载”、“当前任务”、“历史记录”、“设置”。
    *   **右侧 (Content)**: 一个 `QStackedWidget`，用于在不同页面间无缝切换。
*   **页面实现**:
    *   **新建下载页**: 复刻 HTML 中的“英雄式”输入框和卡片式配置面板。
    *   **当前任务页**: 专门展示正在进行的任务列表。
    *   **历史 & 设置**: 保持现有逻辑，但嵌入新的布局中。

#### **3. 组件适配**
*   **Sidebar 组件**: 创建一个自定义的 `NavigationWidget`，处理点击切换页面的逻辑。
*   **任务卡片**: 优化现有的 `TaskWidget`，使其视觉风格与新设计保持一致（更紧凑的进度条，更清晰的信息排版）。

### **实施步骤**
1.  **更新 `styles.py`**: 注入新的 QSS 规则。
2.  **重构 `ui.py`**:
    *   移除 `QTabWidget`。
    *   构建 SideBar + StackedWidget 骨架。
    *   重新组装各个页面组件。
3.  **微调**: 确保交互流畅，页面切换无闪烁。
