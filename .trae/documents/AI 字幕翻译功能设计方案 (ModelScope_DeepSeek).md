明白了，你希望在翻译过程中能有一个**可视化的实时反馈**，而不是仅仅显示一个进度条。这能让你看到 AI 正在翻译哪一句，以及翻译的结果是什么。

### **最终优化方案：带实时预览的 AI 翻译**

#### **1. 依赖管理 (`requirements.txt`)**
*   添加 `openai`。

#### **2. 核心逻辑 (`ai_translator.py`)**
*   **流式回调**: `translate_subtitle_file` 方法将支持一个回调函数 `on_progress(original, translated, percent)`。
*   每翻译完一句字幕，就通过回调发送原文和译文。

#### **3. 新增 UI 组件 (`TranslationDialog`)**
*   这将是一个**非模态对话框**或**独立窗口**，用于展示翻译过程。
*   **布局**:
    *   顶部：进度条和状态信息（“正在翻译第 15/120 行...”）。
    *   中部：一个**滚动的文本区域**（或列表），实时追加显示：
        ```text
        [00:01.500] Hello world -> 你好世界
        [00:03.200] This is a test -> 这是一个测试
        ...
        ```
    *   底部：“取消”按钮。

#### **4. 集成流程**
1.  **设置**: 在设置页配置 API Key。
2.  **触发**: 历史记录页右键 -> “AI 翻译字幕”。
3.  **运行**: 
    *   弹出 `TranslationDialog`。
    *   后台线程逐行调用 API。
    *   翻译结果实时上屏显示在 Dialog 中。
    *   最终保存为 `{视频文件名}_zh.srt`。

这个方案既满足了功能需求，又提供了极佳的用户体验（你可以看着它一句句翻译出来，很有满足感）。如果没有其他问题，我就开始按这个方案执行了！
