通过分析代码，我发现当前的 UI 存在以下主要问题，导致用户体验不佳：
1.  **界面拥挤且层级混乱**：顶部工具栏混合了路径设置、格式选择和操作按钮，缺乏视觉引导。
2.  **单一进度条限制**：底部只有一个进度条和状态标签，这意味着如果同时下载多个视频，进度显示会相互冲突（“打架”）。
3.  **"全部"标签页功能冗余**：它实际上展示的是历史记录，但又不能很好地反馈“当前正在进行的任务”。

我建议进行以下重构来彻底提升体验：

### **1. 视觉美化 (Visual Polish)**
*   **引入现代暗色主题**：创建一个 `styles.py`，使用 QSS (Qt Style Sheets) 为应用应用一套现代、扁平化的暗色主题，优化按钮、输入框和表格的视觉效果。

### **2. 布局重构 (Layout Redesign)**
*   **顶部：核心输入区**
    *   将 URL 输入框放大并置顶，作为核心焦点。
    *   将“下载”和“分析”按钮设计得更醒目。
*   **中部：配置面板 (可折叠/分组)**
    *   将“保存路径”、“格式选择”、“字幕选项”等配置项整理到一个整洁的 `QGroupBox` 中，而不是散落在工具栏上。
*   **主体：任务列表 (Task List)**
    *   **移除** “全部” 标签页中那个令人困惑的表格和单一进度条。
    *   **新增** 一个 **“当前任务”区域**。每当开始一个下载，就在这里添加一个独立的卡片（Task Card）。
    *   **每个卡片包含**：视频标题（如已知）、独立的进度条、实时速度/剩余时间、以及独立的“取消”按钮。

### **3. 交互逻辑优化**
*   **支持多任务并行显示**：重构 `start_download` 逻辑，不再绑定全局进度条，而是动态创建 `TaskWidget`，让每个下载任务都有自己独立的 UI 反馈。
